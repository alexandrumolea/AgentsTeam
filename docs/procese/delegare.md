# Proces: delegare

**DRI:** Tudor. **Scop:** agentul face exact ce trebuie din prima.

Fiecare brief către un agent conține:
1. **Ce a spus Alex**, citat exact.
2. **Ce înseamnă „gata”**, adică livrabilul și unde se salvează (`team/<agent>/documente/`).
3. **Ce să citească întâi**: fișierele relevante.
4. **Cine mai lucrează în paralel** și **cine deține fiecare decizie** (de ex.: numele sunt ale Mariei, câmpurile ale lui Radu). Lecția din 2026-11-15.
5. **Limite**: ce nu face, ce nu publică.

După livrare, Tudor verifică rezultatul, potrivește propunerile paralele, notează în `docs/decizii.md` și abia apoi raportează lui Alex.
